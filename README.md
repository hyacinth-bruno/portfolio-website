# Bruno Mbachu - Frontend Engineer Portfolio

A modern, minimalistic portfolio website showcasing my experience as a Frontend Engineer specializing in React, TypeScript, and product development.

## 🌟 About This Portfolio

This portfolio is built with cutting-edge technologies and showcases my professional journey, technical skills, and work experience. It features a sophisticated dark theme with yellow accents, smooth animations, and responsive design optimized for all devices.

## ✨ Features

- **Modern Tech Stack**: Next.js 14, React 18, TypeScript, and Tailwind CSS
- **Smooth Animations**: Framer Motion for elegant page transitions and scroll effects
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices
- **Performance Focused**: Fast loading times and optimized bundle size
- **SEO Optimized**: Proper meta tags and semantic HTML
- **Accessibility**: WCAG compliant with keyboard navigation support
- **Professional Design**: Clean, minimalistic aesthetic with attention to detail

## 🚀 Quick Start

### Prerequisites

- Node.js 18 or higher
- Yarn package manager

### Installation

1. Extract the portfolio files to your desired location

2. Install dependencies:
```bash
yarn install
```

3. Run the development server:
```bash
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## 🎨 Customization

### Update Content

The portfolio currently contains my (Bruno Mbachu's) information. To customize:

1. **Personal Info**: Update text in `components/Hero.tsx`
2. **About Section**: Modify content in `components/About.tsx`
3. **Experience**: Update the `experiences` array in `components/Projects.tsx`
4. **Skills**: Modify skill categories in `components/Skills.tsx`
5. **Contact Details**: Change information in `components/Contact.tsx`

### Change Colors

Edit CSS variables in `app/globals.css`:

```css
:root {
  --background: 240 10% 3%;    /* Dark background */
  --foreground: 60 9% 98%;     /* Light text */
  --accent: 48 96% 53%;        /* Yellow accent */
  --muted: 240 5% 25%;         /* Muted text */
  --border: 240 6% 15%;        /* Border color */
}
```

### Modify Fonts

The portfolio uses Libre Franklin and JetBrains Mono from Google Fonts. To change:

1. Update the `@import` statement in `app/globals.css`
2. Modify the font family variables
